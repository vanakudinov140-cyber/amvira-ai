Что выложить в репозиторий / в архив для Amvera (всё в одной корневой папке):

  amvera.yml          — конфигурация сборки и запуска
  requirements.txt    — зависимости pip
  app.py              — код бота
  arial.ttf           — шрифт для PDF и графика (обязателен для кириллицы)

Дополнительно (по желанию):

  .gitignore          — чтобы не заливать .env и мусор в git
  env.example         — подсказка по именам переменных окружения

В панели Amvera задайте переменные (см. env.example):

  TELEGRAM_BOT_TOKEN
  GIGACHAT_CREDENTIALS
  ADMIN_IDS             — необязательно, иначе берутся значения по умолчанию в коде

Лог bot_log.txt создаётся при работе; при пересборке контейнера может обнуляться,
если не перенесёте запись логов в постоянное хранилище /data (отдельная доработка).

Шрифт arial.ttf уже лежит в папке (скопирован с вашего ПК). Для публичного
репозитория проверьте лицензию на распространение шрифта; при необходимости
замените на свободный TTF и поправьте имя файла в app.py.
